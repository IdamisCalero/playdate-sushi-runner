# Playdate Sushi Runner

🍣 An endless runner game for Playdate where you control a piece of sushi running on a conveyor belt!

## How to Play

- **Use the crank** to move your sushi left and right
- **Avoid obstacles** like soy sauce bottles, chopsticks, bowls, plates, ginger, and wasabi
- **Build your score** by avoiding each obstacle (1 point per successful dodge)
- **Speed increases** as your score grows - stay sharp!
- **Game ends** when you collide with an obstacle
- **Press B** to restart after game over

## Game Features

✅ Crank-based movement control
✅ 6 different obstacle types with unique graphics
✅ Progressive difficulty - game speed increases with score
✅ Dynamic spawn rate - obstacles appear more frequently as you advance
✅ Score tracking system
✅ Game over and restart functionality
✅ Smooth conveyor belt animation

## Obstacle Types

- 🥫 **Soy Sauce** - Bottle-shaped obstacle
- 🥢 **Chopsticks** - Parallel lines
- 🍲 **Bowl** - Rectangular container
- 🍽️ **Plate** - Circular obstacle
- 🫚 **Ginger** - Textured wavy shape
- 💚 **Wasabi** - Triangle-shaped (hot!)

## Controls

- **Crank** - Move sushi left/right
- **B Button** - Restart game after game over

## Difficulty Progression

Every 500 points:
- Game speed increases by 0.5
- Obstacles spawn more frequently
- Challenge intensifies!

## Building

Requirements:
- Playdate SDK installed

**Option 1 - Using build script:**
```bash
build.bat
```

**Option 2 - Using VS Code:**
Press Ctrl+Shift+B

**Option 3 - Manual build:**
```bash
pdc source/ SushiRunner.pdx
```

## Tips

- Start with gentle crank movements to learn the timing
- Watch the speed indicator - it tells you how fast the game is moving
- Obstacles spawn randomly - stay alert!
- Each dodge counts - rack up that high score!

Good luck! 🍣✨
